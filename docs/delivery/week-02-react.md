# Week 2 React 查询页面验收

## 完成范围

- `/` 首次访问请求真实任务列表，显示名称、中文状态及颜色、文件名、记录统计、创建时间、详情入口。
- 状态筛选与 URL 同步，切换筛选回第一页，翻页保留状态与 page_size，浏览器前进/后退由 URL 驱动。
- `/jobs/:jobId` 请求真实详情，展示统计、重试次数、源文件、三个时间及最近错误；不存在时显示明确反馈和返回入口。
- 时间使用浏览器本地时区，固定为 YYYY-MM-DD HH:mm:ss，缺失显示 —。
- 加载提示、空数据、错误重试和未匹配路由 404 均有独立界面；请求切换时取消旧请求，避免旧结果覆盖新筛选。
- 集中 API 客户端和响应类型；创建任务按钮连接可用的 `/jobs/new` CSV 上传表单。

## 验证结果（2026-09-18）

- TypeScript 类型检查、Vite 生产构建通过。
- 3 项 Node 原生自动测试通过：分页与筛选参数、本地时间与缺失值、成功/业务错误/非 JSON 响应。
- 浏览器连接真实 API，查看现有 Worker 验收任务及详情；UTC 08:12:02 显示为浏览器本地 18:12:02。
- 访问 status=SUCCESS&page=2&page_size=1，点击上一页后 URL 为 status=SUCCESS&page=1&page_size=1，筛选保留。
- 切换失败状态，URL 同步 FAILED，显示空状态和创建按钮。
- page=0 返回参数错误，页面显示加载失败和重试；点击重试仍安全显示该错误。
- 不存在 UUID 显示任务不存在；/not-found 显示 404；创建入口显示名称与 CSV 文件表单。

复跑自动检查：`sh scripts/check.sh`。启动页面：`docker compose up -d --build web`，访问 http://127.0.0.1:5173/ 。
