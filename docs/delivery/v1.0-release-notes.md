# SyncFlow V1.0.0 Release Notes

日期：2026-09-25。交付形态：可复现的本地部署源码包。版本号为 `1.0.0`；本节整理发布包，不创建 Git 标签、GitHub Release 或替代第九节 PR 审查。

## 已交付

- React 上传 CSV，名称选填，文件后缀/默认 10 MB 前置校验，提交防重复，失败保留输入。
- API 保存文件与任务、投递 Redis 后返回 201；独立 Worker 读取同一个上传卷，进行真实 CSV 校验、规范化、去重和 MySQL 写入。
- UTF-8/BOM、固定四列表头，默认最多 10,000 条非空数据记录；DECIMAL(12,2) 金额与 DATE 日期准确存储。
- 每 250 条记录独立提交；行错误保留原始数据、行号、字段和原因。单批写入失败只回滚本批，累计统计以实际提交为准。
- SUCCESS / PARTIAL_SUCCESS / FAILED 终态，列表与详情、3 秒刷新、错误分页查询和页面入口。
- Compose 运行 MySQL、Redis、API、独立 Worker、前端及一次性数据库初始化服务；前端提供构建产物，健康检查等待 API 与 Web 可用。
- 配置示例、固定正常/异常样例、测试报告与截图、部署说明和演示/复盘初稿。

## 使用与升级

按 [本地部署说明](../deployment/local-v1.0.md)启动。已有开发库通过可重复执行的 `mysql-init` 补齐 PARTIAL_SUCCESS 状态约束并保留数据；不要为升级删除数据库卷。停止服务默认保留 MySQL 和上传卷。

包中包含源码、锁定依赖、Compose/Dockerfile、配置示例、样例和验收资料；不含 `.env`、凭据、数据库卷、上传文件、依赖缓存、Git 历史或原始 PDF。通过外部 SHA-256 文件与包内 `MANIFEST.sha256` 校验内容。

## 已知边界

- 当前为本地单机 V1.0，无登录、租户隔离或公网部署配置；端口绑定 127.0.0.1。前端使用 Vite preview 提供构建页面和本地代理，不作为公网生产服务器方案。
- Worker 单进程串行处理。预留的并发、超时、最大重试、退避、幂等 TTL 配置尚未执行；无自动重试、取消、幂等创建或数据导出。
- Redis BLPOP 没有消息确认；Redis 重建可能丢失排队消息，Worker 崩溃时已出队任务可能停在 RUNNING，需要人工核查。MySQL 与文件卷持久化不等于自动任务恢复。
- 数据库持续不可用时，无法保证失败状态能回写；已提交批次保留。不支持跨 MySQL、Redis、文件系统的原子提交。
- 前端上传上限固定为默认 10 MB；服务端可配置更小并返回明确错误，调大服务端限制不自动放宽前端。
- 页码分页在运行中新错误写入时可能改变页边界；无跨请求冻结快照、性能 SLA 或自动数据保留策略。
