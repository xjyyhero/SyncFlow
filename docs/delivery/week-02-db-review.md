# MySQL 自动测试与人工审查

## 一键运行

在项目根目录运行（Python 3.11+、Docker 可用，项目 API 已启动）：

```sh
python3 scripts/review-db.py
```

如 API 尚未启动，先运行：

```sh
docker compose up -d --build --wait api
```

脚本依次执行：

1. 在独立临时 MySQL 中执行现有 6 项集成测试，采集每个用例的耗时、预期值、实际值、通过/失败结果。
2. 清理测试容器；开发库不参与测试数据写入。
3. 通过运行中 API 的实际配置连接 MySQL，使用只读一致性事务查询当前所有基础表。
4. 导出真实 `SHOW CREATE TABLE`、`SHOW FULL COLUMNS`、`SHOW INDEX` 和表内数据，生成可展开的 HTML 审查报告。

测试失败或数据库导出失败时，脚本仍生成本次错误报告并返回非零退出码，不把旧报告当作本次结果。

## 输出文件

每次运行创建独立目录 `output/db-review/<UTC时间>/`，终端会打印完整报告路径。

| 文件 | 用途 |
| --- | --- |
| `index.html` | 用浏览器打开，可展开测试断言、索引、真实建表 SQL，查看当前数据 |
| `test-results.json` | 本次测试的原始结果、逐条断言和失败详情 |
| `database-snapshot.json` | 开发库真实快照，包含数据库名、MySQL 版本、采集时间、列定义、索引、数据 |
| `schema.sql` | 从实际 MySQL 读取的建表语句，保留引擎、排序规则、默认值、索引和检查约束 |
| `table-1.csv` 等 | 各表数据，HTML 对应表区块提供下载入口，表名映射也见 JSON 的 tables 顺序 |

每表最多展示和导出前 500 行；总行数和是否截断均显式记录。当前三表为空，所以此次导出为完整数据。CSV 空表仍保留字段表头。JSON 是保留 NULL 及字段信息的审查原始资料；CSV 仅便于查看。

报告是有时间戳的静态快照，不是实时数据库管理工具。HTML 可直接在本机浏览器打开，不依赖外部资源。导出目录已被 Git 忽略，不自动上传。

## 已验证的测试例子

- **状态流转**：默认 PENDING；提前完成被拒绝；开始、完成成功；重复操作不覆盖首次开始时间。
- **连接故障**：正常连接可用；连接端口 1 实际失败，健康检查返回 503 且无凭据泄露。
- **精度与约束**：`1234567890.12` 精确存储；同任务重复业务 ID、小写 ID、非法状态及负计数被数据库拒绝。
- **重复初始化**：先写入任务，再初始化两遍；结构和已有数据保留。
- **事务回滚**：模拟异常后任务创建回滚；失败状态和错误记录一起提交或回滚；支持 JSON 行摘要。
- **稳定分页**：同创建时间的 a/b/c，每页 2 条，第一页 c/b，第二页 a；覆盖空页、最大页大小、非法参数及参数化查询。
